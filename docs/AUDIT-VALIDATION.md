# 外部审计报告核验记录

核验基线：`ba202da`。输入：用户提供的《FujiPic 安全与可靠性审计报告》。以下区分已确认缺陷、风险缓解和需要产品策略的建议。优先级沿用报告编号，不代表认可全部严重性评级。

## 已确认并处理

| 报告项 | 核验与处理 |
|---|---|
| F-01 | 成立。`ParseForm` 不解析 multipart 文件，但原来的 `FormValue` 会隐式触发解析。非上传 Web POST 仅接受 urlencoded，默认 64 KiB；批量删除/API 上限 1 MiB；上传有独立上限。缺少 CSRF cookie 立即失败，表单解析失败仍不能靠 header 绕过。登录/注册请求的 IP 限流位于表单解析前。 |
| F-02 / L1 | 成立。登录/注册邮箱原始输入超过 254 字节直接拒绝、不回显；邀请码限制 128 字节；限流 key 使用固定长度摘要，最多 10000 条，容量满时拒绝新 key，过期后恢复。仍使用单锁，但扫描与存储规模有明确上界。 |
| F-03 | 成立。就绪检查合并并发请求，并缓存成功和失败结果 10 秒。公开接口保留以兼容现有探针；每个实例最多每 10 秒一次云探测，响应仍为 no-store。初次或过期后的请求可能等待最多 5 秒；存活检查独立。 |
| F-04 | 成立。新增迁移 `0008`，两个队列都有持久化 `next_attempt_at` 及索引；失败按 30 秒至 1 小时退避，持续重试，不再在 10 次后永久停止。旧版耗尽任务升级后自动恢复。失败保留错误/次数并记录日志。选择持续自动恢复而非新增不可重试的死信状态；未增加监控平台或管理员重放 UI。 |
| F-05 | HTTP 源站模板默认暴露端口和宽泛代理信任属实。模板改为 loopback 发布、显式 origin secret/purge 配置、默认不信任代理，并补资源限制和日志轮转。仍允许操作者显式选择 `none`（不用 CDN 的场景）；推荐公共入口仍是 Cloudflare Compose。 |
| F-06 | 成立。默认 S3 HTTP 客户端有 5 分钟整体请求超时；维护中的每个云操作有 30 秒期限，删除、purge、本地清理分别运行，故障互不阻塞。 |
| F-07 | 固定截断属实。用户、邀请码、审计日志可通过管理页页码访问，排序含稳定的唯一键；用户筛选提供服务器端邮箱搜索，最多返回 200 个搜索结果并包含所有已选用户；验证 ID 依据完整数据库，不把当前搜索页误当全部用户。搜索使用数据库子串匹配，不声称是常数时间检索。 |
| F-08 | 无上限原子删除属实。单批最多 1000 张，事务内再次检查上限，超限不修改任何图片。超限列表仅计数，不再流式计算全部结果 fingerprint；较小批次保留原子删除和防陈旧校验。未引入异步任务、进度或取消机制。数据库计数本身仍依赖匹配规模；`busy_timeout` 不控制 `database/sql` 等待连接，报告对此描述不准确。 |
| F-09 | 成立。迁移回填 NULL 维度，所有相关读取/删除查询同时使用 COALESCE 兼容之后导入的 NULL。 |
| F-10 | 多请求临时空间放大成立。全局最多 8 个 HTTP 上传，在 multipart 解析前非阻塞准入；Linux/macOS 检查应用临时目录与系统临时目录的可用空间，预留八槽最坏临时开销及 64 MiB 余量。Compose app tmpfs 调整至 256 MiB。水位是准入检查，不是磁盘预留，其他进程仍可能竞争磁盘。保留“先计算哈希再检查配额”：同图去重不额外占用配额，提前拒绝会破坏已满配额用户的去重上传。其他平台只有并发保护。 |
| F-11 | 清空操作没有记录属实。删除历史和写入包含操作者、IP、删除条数的新审计记录在同一事务完成。未引入超级管理员或双人审批。 |
| F-12 | 成立。账号级登录计数移至 Turnstile 成功后；注册区分较宽的请求级 IP 限流和验证后的注册配额。账号限流仍是固定窗口防暴力猜测，不声称能消除通过人机验证的分布式锁定。 |
| L2 | 降低损坏哈希的允许资源上限至 256 MiB、6 次、16 路，正常生成的 64 MiB / 3 次 / 2 路保持兼容。 |
| L4 | 硬删除已清理、已脱离自定义桶的墓碑可能重新排入默认桶任务，属实。新增迁移修改触发器：只对尚未软删除的行硬删除时排队；软删除已事务化排队，不重复推断桶。 |
| L5 | 虽然上传只接受 public，数据库允许 private。图片源现显式拒绝非 public 行。 |
| L6 | 成立。根路由仅匹配 `/`；不存在的 API 返回 JSON 404。 |
| L7 | 成立。页面渲染只接受 Web session 用户，不再因 Bearer 请求显示已登录导航。 |
| L8 | 新增活跃图片用户索引、与实际桶过滤表达式匹配的索引及 token 过期索引。统计仍使用实时 SQL，没有引入汇总表。 |
| L10 | Token argv 暴露与删除后只警告属实：改用环境输入及 curl header 文件，轮询主 URL/别名删除后 404，失败退出。上传状态原本已有 case 200/201 校验，不属于漏检；继续保留去重图片保护。 |
| L11 | 成立。生产拒绝 memory，默认 S3 endpoint 校验 URL 且生产要求 HTTPS。 |
| L12 | 云操作有期限并响应取消；HTTP 优雅关闭超时后显式 Close 活跃连接。worker 仍等待取消完成后才关闭数据库，不提前关闭仍在使用的数据库。 |
| L13 | 成立。创建会话事务保留当前会话及最近使用的另外 49 个，淘汰更旧/过期会话。 |

## 未作为缺陷直接改变的建议

- **F-13：自动保留/清除策略。** 软删除墓碑用于重复删除幂等性；审计历史用于追溯。无界增长是运维容量问题，但“30 天后删除”并非现有产品约定。新增活跃记录索引和分页减少热路径影响；本次不自动销毁历史数据，也不自动 VACUUM。若增加清除，需要明确保留期、幂等响应期限和备份策略。
- **L3：迁移命名匹配。** `_` 确实是 LIKE 通配符，但该规则用于为可能与生成名称碰撞的旧名称追加唯一桶 ID，不影响对象路径或凭据。极端名称可能额外改名；不修改已发布迁移或猜测恢复已有名称。
- **L9：Caddy 与应用大小限制。** 属于需同步配置的两个独立边界，现有部署文档已明确提高 `MAX_UPLOAD_BYTES` 时同步调整 Caddy 和 CDN 上限。本次不引入配置生成器。
- **L14：注册邮箱存在性提示。** 当前为有意的用户反馈；有效邀请校验顺序和统一提示可另作产品取舍。保留现有提示，已有 Turnstile 和限流仍生效。

## 验证边界

Go 回归测试覆盖请求边界、缓存探针并发、队列退避/恢复、NULL 图片、批量上限、分页、搜索选中范围、会话上限、生产配置和清理超时。浏览器测试验证上传及筛选/删除交互。未把静态配置检查或本地存储替身等同于真实 Docker、S3、Cloudflare 部署验收。
