# 2026-11-11 管理功能、图片别名与全库复查

## 功能范围

- 邀请码默认单次，可指定次数或显式选择不限次数；注册和次数消费在同一事务内完成。
  迁移 `0007` 保留旧邀请码的单次限制与已使用状态。
- 管理员可一键清空审计日志，需要管理员 Cookie 会话及 CSRF；清理使用原子 DELETE，
  后续活动可以继续写入新日志。
- `PUBLIC_BASE_ALIASES` 提供额外图片域名，API 返回 `alternate_urls`，图库支持复制链接。
  删除时全部已配置域名的刷新任务与软删除、配额变更在同一事务内提交。

## 复查发现与修复

本轮阅读应用 Go 代码及测试、SQL 迁移、前端模板与脚本、CLI、CI 和部署配置。

| 问题 | 修复 | 回归覆盖 |
| --- | --- | --- |
| 图片别名按完整 Host 比较，端口等写法可能绕过图片专用隔离 | 统一 hostname，忽略端口、大小写与 DNS 尾点；拒绝配置冲突 | config/server 的别名配置及 Host 写法测试 |
| 上传失败后，远端清理耗尽超时会阻止配额归还 | 对象清理与预留释放使用独立超时预算 | 真实清理超时后，检查用户/桶预留释放及清理任务保留 |
| S3 `NoSuchBucket` 被误判为对象不存在 | 明确桶缺失继续作为存储失败处理 | 通过 HTTP S3 测试服务检查读取错误及删除重试语义 |
| 通用 CDN 刷新忽略响应读取错误或过长响应 | 完整读取响应并限制为 64 KiB，读取失败或超限返回错误 | 截断响应和超限响应测试 |
| 静态资源 URL 固定，升级后可能使用缓存的旧 JS/CSS | 模板资源 URL 增加 SHA-256 内容版本 | 校验页面链接哈希及对应资源实际字节 |
| CDN 验收脚本对去重结果执行删除，可能删除原有图片 | 去重时停止并保留已有图片 | 执行真实 shell 脚本，确认不触碰去重图片 |

## 验证结果

以下检查均在本地通过：

```text
go build ./...
go test ./...
go test -race ./...
go vet ./...
python3 scripts/test-browser.py
CADDY_BIN=<本地 Caddy> python3 scripts/test-cloudflare-proxy.py --host
```

浏览器回归使用真实 Chromium 和项目 JS；Caddy 回归使用临时端口、本地后端与测试证书，
覆盖 TLS、来源 IP 门禁、图片域名路由和请求头隔离。

`go run golang.org/x/vuln/cmd/govulncheck@latest ./...` 报告调用路径受影响漏洞为 0，
导入包漏洞为 0；依赖模块中另有 1 项漏洞，但扫描未发现代码调用相关漏洞路径。

本次未执行生产部署、Docker 构建或真实云端双域名 CDN 验收。Cloudflare Custom Hostnames
仍需在部署时确认域名、Host/SNI、证书、缓存和刷新覆盖，详见
