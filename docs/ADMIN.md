# 后台管理与存储桶池

管理员通过网站域名登录后访问 `/admin`。后台只接受管理员 Cookie 会话；
API Token 即使属于管理员，也不能访问管理页面或提交后台表单。写操作需要 CSRF 校验。

## 创建普通用户

在“用户 → 添加普通用户”填写邮箱和初始密码（10–200 个字符）：

- 无需邀请码，不受开放注册开关影响；创建角色固定为普通用户。
- 新用户处于启用状态，配额取 `DEFAULT_QUOTA_BYTES`，创建后可在用户列表调整。
- 密码以 Argon2id 哈希保存，创建操作不切换管理员当前会话。
- 用户可在设置页修改密码；系统目前没有强制首次登录改密流程。
- 重复邮箱被拒绝，每位管理员每小时最多尝试创建 30 次。

## 查看与删除全部用户图片

进入“查看和管理全部用户图片”（`/admin/images`），每页 60 张，按上传时间倒序显示，
包括上传者邮箱、文件名、尺寸、大小和时间。

删除会软删除元数据、释放图片所属用户配额和桶容量，并安排对象删除与 CDN 刷新；
对象删除失败由后台重试，审计记录实际操作的管理员。重复删除不会重复释放配额。
CDN 刷新是最终一致的，浏览器本地缓存和已经下载的副本不会被撤回。

普通 `/api/v1/images` 列表、详情和删除仍只允许操作本人的图片，管理员 Token 也不例外。
图片 URL 本身是公开访问链接，不能用作敏感资料的访问控制。

## 添加存储桶

默认桶来自 `S3_*` 环境变量，优先级默认 `0`；自定义桶默认优先级 `100`。
添加自定义桶需要稳定保存的 `STORAGE_ENCRYPTION_KEY`。

1. 云上预先创建私有桶，准备对应租户的对象读写、删除凭据。
2. 填写桶名、端点和区域。OCI 使用 Customer Secret Key，勾选 **path-style**；
   端点中的 namespace 和 region 必须与目标桶对应，不要混用其他租户或区域。
3. 设置容量及优先级，点击“添加并验证”。应用执行 PUT → GET 内容核对 → DELETE 探针。
4. 探针成功才把加密凭据保存到数据库并启用桶，无需重启。

`S3_FORCE_PATH_STYLE=true` 只配置环境默认桶；自定义桶使用各自表单里的 path-style 选项。
故障步骤和加密密钥说明见 [OCI 排查](OCI-TROUBLESHOOTING.md)。

## 容量单位与调度

添加和编辑容量使用相同的小数输入规则，单位为 **GiB**，`0` 表示不限。
1 GiB = 1,073,741,824 字节，1 GB = 1,000,000,000 字节。后端精确换算并向下取整为字节。

| 目标 | 表单输入（GiB） | 保存字节数 |
| --- | --- | --- |
| 约 19 GB，略留余量 | `17.69` | 18,994,492,866 |
| 精确 20 GB | `18.6264514923095703125` | 20,000,000,000 |
| 20 GiB | `20` | 21,474,836,480 |

容量展示会四舍五入（例如 20 GB 显示约 18.6 GiB），编辑输入保留精确值。
新上限不能低于当前已用/预留容量。

上传按优先级从小到大选取启用且容量足够的桶，原子预留空间；所有桶满时返回 507。
这是容量溢出，不是请求失败自动切换。禁用桶会停止向其分配新上传，已有图片仍从原桶读取。
默认桶若容量不限且启用，通常会一直优先使用它。

每个真实桶只注册一次。限额只统计本应用管理的活跃图片，不覆盖外部写入、版本历史、
删除重试期间的残留、备份或云服务费用。删除桶前须清空图片、待删除任务和进行中的上传；
默认桶不能删除。保留数据库与原加密密钥的配套备份。
