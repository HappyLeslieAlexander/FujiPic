## 其他加固

- 普通文件路径的数据库在 SQLite 打开前创建/收紧至 0600；SQLite URI 调用路径保留原语义，运维需保护数据库目录和 WAL/SHM、备份。未声称所有 URI 路径均自动 chmod。
- 拒绝重复 session/CSRF Cookie；没有切换 `__Host-` cookie 名称，因此没有宣称完全消除兄弟子域 cookie tossing。受信域部署仍重要。
- 登录/注册 IPv6 预算按 /64 归一，审计 IP 保留原地址。
- 邀请码改为 128 位随机。数据库中仍保留邀请码以支持现有管理员管理界面；哈希存储和密钥轮换属于后续 schema/产品工作。
- 独立图片域、CDN 出口保护、源站网络 ACL、密钥轮换、多实例共享限流属于部署边界；不能仅靠代码测试证明云端配置正确。

## 升级注意

生产新增启动条件：站点/图片 HTTPS、至少 32 字节 `ORIGIN_SHARED_SECRET`；通用 `compose.prod.yml` 需设置准确 `TRUSTED_PROXY_CIDRS`。API 省略 scope 仅授予 upload，需要读取/删除的脚本应显式指定。`TOKEN_TTL` 默认 2160h；显式设置 0 仍允许永久 token。审计日志超过 90 天会分批移除，需长期保留时先导出。Web offset 页码超过 1000 返回 400。

启用新缓存策略前清除旧 CDN 副本，确保 CDN 规则尊重源站 TTL；已存在的浏览器 immutable 副本无法通过本次响应头追溯撤销。
