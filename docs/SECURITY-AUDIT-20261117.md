## 缓存与删除

- CDN：继续 `CDN-Cache-Control: public, max-age=31536000`。
- 浏览器：继续 `Cache-Control: public, max-age=0, must-revalidate`。
- 删除：持久化 purge 与对象删除独立重试；本次补全直接 SQL/用户级联删除的 purge 义务。迁移不能推导升级前已经丢失的历史 URL，也不能撤回下载到第三方的内容。
- `cdn_purge_origins` 在服务启动、后台任务运行前更新。离线 SQL 删除使用上次成功启动持久化的配置；修改域名或 purge 开关后须启动服务使配置生效。

协议依据：[RFC 9111 §3.3](https://www.rfc-editor.org/rfc/rfc9111.html#section-3.3)、[§3.4](https://www.rfc-editor.org/rfc/rfc9111.html#section-3.4)。规范核查不等于实测任意 CDN 的实现。
